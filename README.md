按键总体逻辑是 上下按键单击为选择或者数据加减，双击上按键为确定，双击下按键为返回。

菜单: 
1. 时间
 
   1.1  时间展示 （如   12 ：00 ：00
                       2026-10-21 ）
   
   1.2  在1.1的基础上双击上按键，进入选择 要修改的时间单元，通过按键上下选择，选择的单元都是取反显示的，方便辨认。

   1.3  选好单元后，双击上按键进入，开始修改时间，改好后双击上键确认，确认完成会进入到1.2，，不确认直接下键双击表示取消并退出，也会回到1.2
   
2. 闹钟
  2.1 闹钟按键逻辑与时间想通， 此界面是闹钟时间展示（如： 08:00：00）
  2.2 选择闹钟设定单元
  2.3 修改选择的闹钟单元，闹钟时间到达触发后，会有30s的时间让蜂鸣器以2s为一个周期，前100ms和200-300ms 分别短鸣两声，2s内的其余时间停止鸣叫。作为闹钟到达的声音的提醒。
  
3. 秒表
   3.1 秒表的展示 （如 ： 秒表000小时
                         00分：00秒
                         000
                               开始）
   3.2 双击开始后，直接开始计时，最下方的000也就是ms会跑马，然后上单击会暂停时间，下单击会清空时间，
   
4. 计步器
   4.1 通过 IIC与mpu6050通讯，获得六轴传感器的值，然后进行数据分析，计算步数。有一个清空按钮，表示重新计数
   
5. 设置
    5.1 设置oled的对比度，进入后，可以通过  单击上下按键来修改对比度数值，上双击确认后返回主菜单，下双击返回主菜单。

菜单部分完成。屏幕添加30s不操作会息屏的设置。息屏后，只要按键有操作或者闹钟触发就会显示。
